# Atelier cognitif

Application **indépendante** d’entraînement cognitif et d’hygiène visuelle.

Elle n’est **pas** une fonction T3US : autre dossier, autre serveur, autre persistance (navigateur local uniquement).

## Démarrer

```bash
cd app-cognitive
npm install
npm start
```

Ouvrir **http://localhost:4100** (T3US reste sur `:3000` / API `:4000`).

Build + serveur statique :

```bash
npm run build
npm run server
```

## Contenu

5 domaines × 4 exercices : mémoire, raisonnement, vitesse, concentration & flux multiples, yeux & écrans.

Sessions bornées (5 / 10 / 15 min). Pas de compte T3US, pas d’API T3US.
